# Changelog

All notable changes to this repo. Keep newest first.

## [0.4.0] — 2026-10-07

### Added
- Adult colony depth. Assign each colonist to garden, scrap, clinic, watch, or rest. Traits change hunger.
- Buildings spend scrap: garden beds, clinic cot, watch post, gate timber. Jobs only pay off if the building exists.
- Night push spends ammo from the watch and can injure or mark someone missing. Search can bring them back.
- Wide screens use two columns. Phones keep a wrapping button row. No canvas.

### Changed
- Audience is the owner, not children. The weekly task stays on Ashward.

## [0.3.0] — 2026-10-07

### Added
- Ashward text colony. Stocks, four colonists, a gate, hourly tick, offline catch-up, endless district names.

### Changed
- Retired the top-down sprout RPG.
