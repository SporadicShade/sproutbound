# Changelog

All notable changes to this repo. Keep newest first.

## [0.3.0] — 2026-10-07

### Added
- Ashward, a text colony log. Stocks, four colonists, a gate, and a garden.
- Hourly tick while the page is open, and catch-up from the saved timestamp when it is opened again.
- Scout names a new city district forever. There is no last district.
- Horde pressure rises over time. The gate spends scrap to hold. A bad hour can tire or sideline a colonist without a gore description.

### Changed
- Retired the top-down sprout RPG. The phone canvas, joystick, and arrow pad are gone. The scheduled weekly increment now builds Ashward.

## [0.2.2] — 2026-10-07

### Fixed
- Arrow buttons were added because the joystick did not fit or move on a phone. That control bar is removed in 0.3.0.

## [0.2.1] — 2026-10-07

### Fixed
- Joystick drag tracking. Superseded by the text colony.

## [0.2.0] — 2026-10-07

### Added
- Pause bag and shrine shop for the retired meadow prototype.
